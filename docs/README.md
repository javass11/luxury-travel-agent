## 🚀 How It Works

The documentation is automatically published to GitHub Pages when you push to the `main` branch. The site is served from the `docs/` folder.

### GitHub Pages Configuration

GitHub Pages is configured to:
1. Source: `main` branch, `/docs` folder
2. Theme: Minimal (Jekyll)
3. URL: https://javass11.github.io/luxury-travel-agent

### To Enable/Modify

In your GitHub repository settings:
1. Go to Settings → Pages
2. Source should be: `main` branch, `/docs` folder
3. Theme should be selected (or use custom domain)
4. Save - site will deploy automatically
