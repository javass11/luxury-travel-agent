⚡ Quick Start

Works Without API Credentials

The system works perfectly with demo data - no API keys required!

python -m src.app # APIs return demo data automatically # Visit http://localhost:5000

With Amadeus Flight API (Optional)

export AMADEUS_API_KEY=your_key export AMADEUS_API_SECRET=your_secret python -m src.app # Flight searches now use real Amadeus data

With Redis Caching (Optional)

# Install Redis brew install redis redis-server # Or with Docker docker run -d -p 6379:6379 redis # Set in .env export REDIS_URL=redis://localhost:6379/0

🚀 Deployment

Deploy to Heroku

# Set API credentials (optional) heroku config:set AMADEUS_API_KEY=xxx heroku config:set AMADEUS_API_SECRET=xxx heroku config:set BOOKING_API_KEY=xxx # Add Redis addon (optional) heroku addons:create heroku-redis:premium-0 # Deploy git push heroku main # Run migrations heroku run alembic upgrade head # Verify curl https://your-app.herokuapp.com/api/health
